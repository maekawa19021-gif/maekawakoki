# 前川こうき後援会サイト 修正版

## 修正内容

### 1. スマホ版トップ写真
- スマホ表示で、顔写真を「国民民主党・高松市議会議員（2023年 最年少当選）」と「前川こうき」の間に配置。
- 写真を前回より大きく表示。
- 右寄せではなく中央寄せに変更。

### 2. 議会・市政レポートの読み込み安定化
- PCでGoogleドライブ・Apps Scriptの応答が遅い場合に備え、読み込み待ち時間を長く設定。
- 途中で「読み込み中」の案内を出しつつ、最大60秒まで待機。
- 読み込み失敗時も、Googleドライブのフォルダを直接開けるボタンを表示。
- Apps Script側で市政レポート一覧を10分間キャッシュし、PCでの初回・再読み込みを軽くするよう修正。

## 上書きが必要なファイル

GitHub側：
- index.html

Apps Script側：
- payment_redirect_webapp.gs

その他のHTMLは前回と同じ内容を同梱しています。まとめて上書きしても構いません。

## 重要

payment_redirect_webapp.gs を更新した後は、Apps Scriptで必ず新バージョンとして再デプロイしてください。

手順：
1. Apps Scriptを開く
2. デプロイ
3. デプロイを管理
4. 鉛筆マーク
5. バージョン：新バージョン
6. デプロイ

また、デプロイ設定は以下にしてください。

- 実行するユーザー：自分
- アクセスできるユーザー：全員

config.js の APPS_SCRIPT_URL は、現在利用中のウェブアプリURLを入れてください。
