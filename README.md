# 前川こうき後援会サイト 修正版

## 今回の修正

- 市政レポートは、最初に従来のJSONP方式で取得します。
- PCブラウザの追跡防止・外部スクリプト制限などでJSONPが失敗した場合は、Apps Scriptが返す専用HTMLへ自動的に切り替わります。
- Googleドライブのフォルダ画面そのものは埋め込まず、サイトと同じカード形式でPDF一覧を表示します。
- スマホの顔写真位置調整も維持しています。

## 上書き

GitHub側は、基本的に `index.html` を上書きしてください。
一式で上書きする場合は、ZIP内の同名ファイルをそのまま上書きして構いません。

PC向けの代替表示には、同梱の `payment_redirect_webapp.gs` にある
`reports_iframe` 処理が必要です。Apps Script側も同梱ファイルで上書きし、
「新しいデプロイ」ではなく、現在使っているウェブアプリの「デプロイを管理」から
新バージョンを作成してください。URLはこれまでと同じ `/exec` URLを使用します。

## config.js の注意

`APPS_SCRIPT_URL` にはGoogleドライブのURLではなく、Apps ScriptのウェブアプリURLを入れてください。
必ず `/exec` で終わる本番URLにしてください。
