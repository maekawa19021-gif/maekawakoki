SEO基本ファイル 更新手順

1. sitemap.xml と robots.txt を、GitHubリポジトリの最上位
   （index.html と同じ場所）へアップロードしてください。

2. GitHub Pagesへの反映後、次のURLをブラウザで確認してください。
   https://maekawa19021-gif.github.io/maekawakoki/sitemap.xml
   https://maekawa19021-gif.github.io/maekawakoki/robots.txt

3. Google Search Consoleの「サイトマップ」を開き、
   「新しいサイトマップの追加」に sitemap.xml と入力して送信してください。

注意:
- Google所有権確認用の google～.html は削除しないでください。
- privacy.html は meta robots=noindex のため、sitemap.xmlには掲載していません。
- 今後、政策ページや活動報告ページを追加した場合は、sitemap.xmlにもURLを追加してください。
